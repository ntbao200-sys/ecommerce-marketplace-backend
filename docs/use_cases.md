# Use Cases — E-commerce Marketplace

## 1. Authentication
- Đăng ký tài khoản.
- Đăng nhập và đăng xuất.
- Xác thực và kiểm tra quyền truy cập.

## 2. Customer — Mua hàng
- Xem danh sách và chi tiết sản phẩm.
- Tìm kiếm và lọc sản phẩm theo danh mục.
- Thêm, cập nhật và xóa sản phẩm trong giỏ hàng.
- Đặt hàng.
- Xem lịch sử mua hàng và trạng thái đơn hàng.

## 3. Customer — Bán hàng
- Tạo shop.
- Cập nhật thông tin shop.
- Thêm, sửa và ẩn sản phẩm.
- Quản lý phiên bản sản phẩm, giá bán và tồn kho.
- Xem danh sách đơn hàng của shop.
- Cập nhật trạng thái xử lý đơn hàng của shop.

## 4. Admin
- Quản lý tài khoản người dùng.
- Kiểm duyệt shop.
- Kiểm duyệt sản phẩm.
- Khóa hoặc mở khóa tài khoản theo chính sách hệ thống.
